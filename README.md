# Join 📋

A collaborative project management web application built with **HTML, CSS, JavaScript, Git, Firebase, and AI-powered automation**.

---

## Description

**Join** is a web-based project management tool developed together with other participants from a professional web development training program.

The application helps teams visualize tasks, their current status, and assigned responsibilities in a clear and structured way.  
Users can create, update, and organize tasks to keep track of workflows and team progress efficiently.

The project focuses on real-world web development, teamwork, and the use of modern web technologies.  
Additionally, the application has been enhanced with **AI-powered automation using n8n**, enabling intelligent task creation and workflow optimization.

---

## Features

- Create and manage tasks  
- Assign tasks to team members  
- Visualize task status and progress  
- User-friendly interface  
- Real-time data storage with Firebase  
- Collaborative development using Git  
- AI-powered automation via n8n workflows  
- Email-based task submission  
- Automated AI analysis, categorization, and prioritization of tasks  
- Automatic ticket creation directly in the Kanban board  

---

## AI Automation Extension

The existing Kanban board project **Join** has been enhanced with AI-powered automation using **n8n**.

This extension enables stakeholders to submit feature requests and technical tasks directly via email. Incoming emails are automatically processed, analyzed, categorized, and prioritized using an AI-driven workflow. The system then creates structured tickets directly in the Kanban board.

The goal of this extension is to demonstrate practical AI integration in real-world workflows, providing a clear and transparent automation logic and a smooth user experience — especially for portfolio presentations and demo scenarios.
